## Sobre o desenvolvimento

O desenvolvimento deste site foi relativamente simples, principalmente porque a GAD já havia gostado de outras contribuições que realizei anteriormente.

Por esse motivo, utilizei como base o layout de outro projeto desenvolvido para uma ONG. A estrutura já estava adequada para esse tipo de organização, então o trabalho consistiu principalmente em adaptar o projeto para a identidade visual e as necessidades específicas da GAD.

As principais etapas foram:

- Criação e adaptação das imagens utilizadas no site;
- Inserção das informações da ONG;
- Adaptação da estrutura para os conteúdos da GAD;
- Criação de uma paleta de cores baseada na identidade visual da logo;
- Ajustes de layout e responsividade;
- Implementação de um novo sistema de carrossel vertical para os projetos.

### Carrossel vertical

O principal diferencial implementado neste projeto foi o carrossel vertical para a seção de projetos.

A ONG possui diversos projetos e iniciativas. Inicialmente, pensei em apresentar quatro projetos simultaneamente, mas isso acabaria ocupando muito espaço e poderia deixar a seção visualmente pesada.

Por isso, optei por utilizar um carrossel vertical de tópicos. Dessa forma, é possível apresentar os projetos de maneira organizada sem ocupar uma área excessiva da página.
